# Portfolio Generator

## Run
```
npm install
npm run dev
```

## Deploy (Step 10)
1. Push this folder to GitHub.
2. On Netlify or Vercel, import the repo. Build command `npm run build`, output directory `dist`.

## Publish an exported portfolio on GitHub Pages
1. Click **Download ZIP** and unzip it.
2. Create a repo named `your-username.github.io`.
3. Upload `index.html` and `style.css` to the repo root.
4. Your site goes live at `https://your-username.github.io` in a minute or two.
